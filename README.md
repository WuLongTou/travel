# 宇宙航行 · 真实物理太空飞行器模拟

从太阳系出发，一路飞到可观测宇宙边缘——六层尺度世界连续穿越，
天体引力、轨道速度、飞船性能全部遵循真实物理。

## 快速开始

```bash
npm install   # 首次
npm run dev       # 本地运行（浏览器打开输出地址）
npm run build     # 生产构建（前置 tsc --noEmit 全量类型检查）
npm run test      # Vitest 单测（units/clock/missions/UI 状态机）
npm run typecheck # 仅类型检查
npm run smoke     # 无头冒烟 e2e（六层逐层进入断言 + 游戏 UI 流断言）
```

技术栈（标准 web 游戏栈）：TypeScript 5（strict 全量）· three.js ·
Vite · Vitest（单测）+ agent-browser（e2e）· WebAudio（程序化音效）。
核心领域类型集中在 `src/types.ts`，UI 覆盖层状态机见
`src/core/game-state.ts`。

游戏标准特性：标题画面（开始/继续/重开 + 存档概览）、暂停菜单
（`Esc`/手柄 Start：继续航行 / 设置 / 回到标题，游戏冻结且关闭后
恢复原暂停态）、通关结算画面（12 环全通关触发：任务/发现/卫星/
航程时长统计 + 凯旋音效）、设置面板（`O` 键：主音量滑条/屏幕震动
开关，localStorage 持久化）、跨层黑场转场、撞毁震屏与红闪、新发现
准星脉冲、程序化音效（`M` 静音）、进度 localStorage 持久化。

载入即自动飞行：松开所有按键，飞船自己在引力场中巡航；
**点击任意天体**即自动导向泊车，飞近可自动下潜进入下一层。

## 穿越整个宇宙

六层尺度靠两条规则连续穿越，**顶栏面包屑也可直达任意层**：

- **向上（浮升）**：朝任意方向飞出当前层界（层半径 85%，接近 60% 时
  HUD 有提示），自动浮升到更大尺度——太阳系 → 星际近邻 → 银河系 →
  本星系群 → 室女·宇宙网 → 可观测宇宙边缘。
- **向下（下潜）**：飞近带「飞近可自动下潜」标记的天体（如星际层的
  太阳系、银河层的太阳系邻域），自动下潜进入其内部；也可在信息卡点
  「进入…」或选中后按 `F`。

## 玩法

- **任务链（主线 + 挑战）**：左上角任务挂件串起 12 环——首次接触 →
  泊入行星 → 贴日掠过 → 冲出摇篮 → 比邻之行 → 回到家园 → 卫星巡礼
  （发现 3 颗卫星）→ 银河之心 → 宇宙边缘，之后解锁 3 个只有手动飞行
  才能完成的挑战：引力弹弓（泊入木星后把速度拉高 20 km/s）、掠日
  骑士（0.05 AU 掠日）、低轨信使（1.5 倍半径内伴飞）。
- **卫星可发现**：月球、火卫、伽利略卫星、土卫六等 9 颗大卫星均为
  可选中实体，泊近即计入发现。
- **手柄支持**：左摇杆推进平移、右摇杆环视、RT 加力、LT/LB 升降、
  RB 反推刹车、Y 切换视角、Start 暂停菜单（菜单内 dpad 上下选择、
  A 确认、B 返回；即插即用）。
- **深空环境事件**：太阳系层随机流星雨划过视野；彗星群周期性掠过
  内太阳系（纯视觉氛围，不影响物理）。
- **程序化音效**：引擎轰鸣随推力/加力变化，泊车、任务完成、撞毁、
  跨层跃迁各有提示音（WebAudio 合成，零外部素材）；`M` 静音。
- **发现收集**：首次泊入任一天体计为「新发现」，挂件实时累计。
- **全自动旁观（默认）**：无目标时按所在引力井自动入轨巡航；
  点选天体后自动导向、交会、伴飞泊车；大巡游（`T`）按教学路线
  自动串联各站（到站停留 12 秒），点选其他目标或手动干预即结束。
- **随时手动接管**：按住 `WASD`（前后左右）、`Space`/`C`（上下）、
  `Q`/`E`（横滚）、`X`（反推刹车）、`Shift`（加力）即人工干预，
  松手自动回到全自动航行。接管瞬间时间倍率自动暂降至「1时/秒」
  （高倍率下手动机动会一帧飞出层），松手恢复自动配速。
  鼠标只管环视/缩放，绝不干扰飞行。
- **上帝视角（`G`）**：相机脱离飞船自由浏览（`WASD` 移动、
  `Space`/`C` 或 `Q`/`E` 升降、滚轮调速、`Shift` 加速），
  飞船在背景中继续自动飞，再按 `G` 返回。
- **视角与时间**：`V` 循环追尾/座舱/环绕视角（追尾 = 相机始终锚在
  机尾后上方，随飞船航向转动；鼠标方向遵循游戏常识：右移看右、
  下移看下；座舱视角带机身框遮蔽），`Z` 复位视角；`[` `]` 步进
  时间倍率（手动设置即挂起自动倍率，重选目标恢复），`\` 时钟暂停，
  `Esc` 暂停菜单，`R` 安全轨道重部署，`Tab` 显示帮助。

## 六层世界

| 层 | 内容 | 真实口径 |
|---|---|---|
| 太阳系（AU） | 太阳 + 八大行星 + 主要卫星 + 小行星带/柯伊伯带 + 哈雷/恩克彗星 | GM/半径/轨道速度真实 |
| 星际近邻（ly） | ≤40 光年真实恒星方位 + 参宿四/参宿七远景 | 恒星 GM = GM☉×质量 |
| 银河系（kpc） | 棒旋星系 + Sgr A* + 太阳系位置 | 旋转曲线 220–230 km/s @ 8.2 kpc |
| 本星系群（Mpc） | 银河/M31/M33/麦哲伦云 + 矮星系 | 星系总质量（含暗晕） |
| 室女·宇宙网（Mpc） | 真实星系团方位 + 宇宙网丝（示意） | 星系团总质量 |
| 可观测宇宙（Gpc） | 宇宙网全景 + CMB 边界壳 | 半径 14.2 Gpc |

飞船全层统一为未来离子推进（0.6 m/s²，巡航 ≤300 km/s ≈0.001c，
永远低于光速）；跨尺度航行的节奏由自动时间倍率承担（实时→千亿年/秒）。
