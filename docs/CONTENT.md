# 内容数据 · 来源与示意清单

原则：**不编造数据**。真实数值进 `src/content/data/`；为可读性做的视觉放大
一律标 `schematic`，并在信息卡中说明。

## 数据文件与来源

| 文件 | 内容 | 来源 |
|---|---|---|
| `data/solar.js` | 太阳参数、八大行星（半长轴/半径/公转周期/自转/质量/卫星数）、主要卫星、小行星带与柯伊伯带范围 | IAU/NASA 常用标准值（`SOURCE_NOTE`） |
| `data/stars.js` | ≤25 ly 近邻恒星目录：RA/Dec(J2000)、距离、光谱型、色温、质量、视星等 | Yale Bright Star Catalog / Hipparcos / SIMBAD 标准值 |
| `data/local-group.js` | 本星系群成员：距银河距离(Mpc)、RA/Dec 方向、盘径(kpc) | Wikipedia "Local Group" / NASA / NED；多数距离来自 Karachentsev et al. 2002/2013 |
| `data/super-structures.js` | 室女团、天炉团、后发团、长蛇团等星系团：距离(Mpc)、RA/Dec | Wikipedia / NASA / NED 标准公开数据 |
| `data/cosmos.js` | CMB 信息卡数据、可观测宇宙半径（46.5 Gly ≈ 14.2 Gpc） | Planck/NASA 标准值 |
| （world-solar 内嵌） | 彗星根数：哈雷 q=0.586 AU/e=0.967/75.3 年；恩克 q=0.336 AU/e=0.847/3.3 年 | NASA/JPL 标准值 |

坐标换算：RA/Dec + 距离 → 笛卡尔（`raDecDistToXYZ` / `direction3d`），
银河系为本星系群坐标原点；太阳为恒星坐标原点。

## 示意（schematic）清单

| 位置 | 示意内容 | 真实约束 |
|---|---|---|
| solar 飞船视觉尺寸 | 随跟拍距离放大（真实 ~10 m 不可见） | 物理性能（推进/速度上限）为未来离子推进设定，非现存探测器 |
| solar 行星远场呈现 | 辉光点+标签（接近 <80 半径切换真实球体） | 真实尺度（远场行星肉眼即亮点） |
| solar 照明 | 太阳光不随距离衰减 | 渲染便利：保证外行星可辨识 |
| solar 彗发/彗尾量级 | 彗发 ~10 万 km、彗尾长度示意 | 彗核/轨道/近日点速度真实 |
| galaxy 层星系形态 | 程序化棒旋点云（seed 固定） | 半径 15 kpc、太阳位于 0.55 盘半径（≈8.2 kpc）、棒旋结构按真实形态 |
| local 层星系盘可视半径 | 放大到 0.055–0.075 Mpc（真实 ~0.02 Mpc 不可见） | 距离、方位真实；M31>银河>M33 大小关系真实 |
| solar 彗星轨道 | 真实 GM☉ 数值积分，模拟时间驱动 | q、e、周期、近日点速度公式（vP=√(GM☉(1+e)/q)）真实（NASA/JPL） |
| stellar 南门二双星 | 双星互绕间距演示缩放（真实 ~23 AU 在 ly 尺度不可见）、演示周期 ~44 秒 | 周期 79.9 年、质量比 A:B≈1.1:0.9（半径反比）真实 |
| super 层宇宙网丝 | 节点间连丝为示意拓扑 | 节点（星系团）方位、距离真实 |
| cosmos 层宇宙网与 CMB 壳 | 网状拓扑示意、红移色示意 | 可观测半径 14.2 Gpc；CMB=边界的物理含义 |

## 核实状态（2026-09 全六层逐项核实）

数值层（轨道/质量/距离/光谱）以 NASA 行星概况表、JPL SBDB、SIMBAD/Hipparcos、
McConnachie+2012 本星系群星表、NED、中国家 Wikipedia 条目为准逐项核对：
太阳系数值与权威表高度一致（土星卫星数更新为 274，见 IAU 2025）；
恒星 Wolf 359/范马南星赤经、玉夫/天龙/小熊/NGC 6822/狮子座 II 距离等
已按星表修正；参宿四距离取现代常用值并注明争议区间。
描述层断言（巴纳德星自行、Ross 154 行星候选、拉朗德行星数、M87 最亮、
Zwicky 年份、沙普利=大吸引子等）已修正或弱化；Bootes 空洞 id 拼写修正。
剩余量级级表述（星系团质量、超巨星光度区间）已在信息卡中标注口径或区间。
