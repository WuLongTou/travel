# 宇宙航行 · 架构说明

游戏式太空飞行 + 常开全自动旁观：松开按键飞船自己飞（点选天体即自动
导向泊车），鼠标只管环视；G 键上帝视角相机脱离飞船自由浏览，飞船继续
自动飞。从太阳系到可观测宇宙的六层尺度世界（自动 LOD 连续穿越），
准星拾取天体查看真实数据信息卡。

## 1. 六层尺度世界

每层是一个独立构建的 three.js 场景组，世界单位自洽、渲染策略各自最优。
跨层移动 = Navigator 切换世界（转场镜头重置到该层观测位）+ 自动 LOD
跃迁（飞近可下潜实体自动下潜、远离中心自动浮升，2 秒冷却）。

| id | 层 | 世界单位 | 内容 | 渲染要点 |
|---|---|---|---|---|
| solar | 太阳系 | AU | 太阳+八大行星（真实半长轴/周期）+主要卫星+小行星带+柯伊伯带 | 实体球（程序化贴图+自转）+点光源+轨道线；轨道飞行用真实太阳 GM |
| stellar | 星际近邻 | ly | ≤25 ly 验证近邻恒星（RA/Dec/距离→3D） | 色温点+光晕 sprite+标签 |
| galaxy | 银河系 | kpc | 程序化棒旋星系（140k 星点）+银心 Sgr A*+太阳位置 | 参数化点云+HII 区+银心辉光+盘自转（演示速率）；轨道飞行用演示 GM |
| local | 本星系群 | Mpc | 银河、M31（可下潜）、M33、矮星系（真实方位） | 螺旋小盘+标签 |
| super | 室女·宇宙网 | Mpc | 室女团/后发团等真实星系团方位+宇宙网丝（示意） | 节点+丝点云+团辉光 |
| cosmos | 可观测宇宙 | Gpc | 宇宙网全景（示意）+CMB 边界壳+红移色 | 网点云+稀疏壳点云 |

尺度不真实处一律 `schematic: true`，信息卡标注"示意"（见 CONTENT.md）。

## 3. 三模式控制：AUTO 全自动 / MANUAL 手动干预 / GOD 上帝视角

- **AUTO（默认，无按键即自动）**：松开所有键，全自动接管——点选目标
  天体则**自动导向泊车**。油门按**接近速度**判定并按制动能量曲线
  `√(2·acc·(d−park))` 限总速（系数留半裕量），泄速刹车缩小急转弯半径、
  防绕圈极限环。泊距收紧到**目标自身引力占优区**（g_own ≥ 2×最强第三方
  井，近似希尔球）——占优区内泊位轨道开普勒稳定：到泊位反推减速伴飞，
  坠向天体时机头调离反向**防坠退避**，偏心轨道超当地圆速度 1.3 倍即
  **轨道收拢**，漂出占优区的远地点逐圈压回。向最强井的高速坠落由
  **防井拉起**包线兜底（按制动需求距离触发，全推力反井心）。无自身井
  的目标（彗星等）泊位在第三方井内，退化为**背井驻点悬停**（PD 回归 +
  引力抵消 + 全速度阻尼 + 目标斥力），巡航段期望方向也混入反井心分量
  抵消侧向拖拽。目标漂离泊位外缘微推跟随；进场途中与第三方天体的
  穿越相撞属既有游戏机制（撞毁→重生→继续航行）。
  无目标则按所在引力井智能巡航——低速下坠切向补推**轨道保持**、
  明显超速**引力滑行**、正常**轨道巡航**、主动刹停则**空间停泊**；
  无井层沿航向惯性巡航（低速补推到 0.35 倍上限）。载入宇宙即自动
  开始，无需任何操控——鼠标只管看，飞船自己飞；锁定目标跨层失效
  （跃迁前回调清理 + 目标有效性守卫，杜绝追逐幽灵目标）。
- **MANUAL（手动干预）**：W/S 前后 + A/D 左右 + Space/C 上下六向推进，
  Q/E 横滚，Shift 加力（追踪视角 FOV 拉宽），X 反推刹车；存在实际
  推进/刹车输入时解除目标锁定（纯 Q/E 横滚保持锁定），松开后按当前
  状态继续自动航行（W 前进时在非环绕视角机头平滑导向观察视线，便于
  指哪飞哪）。干预判定按操作分类严格执行（`input.js` 的
  `OP_CATEGORIES`/`FLIGHT_CONTROL_KEYS`）：仅上述飞行操控键构成干预，
  视角/时间/系统操作绝不打断自动航行。
- **GOD（上帝视角，G 键切换）**：相机脱离飞船自由浏览——WASD 平移、
  Space/C 或 Q/E 升降、鼠标转向、滚轮调移速档、Shift 加速；飞船在
  背景中继续全自动飞行，飞行键在此视角只移动相机、绝不干预飞船；
  再按 G 相机无缝回到飞船追尾位。点选天体仍可锁定目标，看飞船
  自动飞过去。
- **大巡游（T 键）**：按各层预设的 `tourStops` 站点（各世界构建器声明，
  由内向外/由近及远的教学顺序）自动串联巡游——自动导向泊车到站伴飞，
  停留 12 秒后前往下一站，末站循环回首站；每站自动弹出信息卡充当
  讲解。到站判定复用自动导航泊距（进入 1.5×泊距圈持续 1.2 秒）；
  手动飞行干预、点击改选其他目标、跨层跃迁均终止巡游（HUD 提示），
  观察类操作与上帝视角不受影响；无路线的层（cosmos）按 T 提示
  「此尺度层没有巡游路线」。HUD 显示 `大巡游 i/N · 停留 xs` 进度。
- **视角（V 键循环）**：追踪 / 座舱（舱内 360° 转头环顾） / 环绕；
  鼠标移动 = 全向环视（100% 不干扰机头航向与自动航行），右键/中键拖拽
  平移视角，滚轮缩放，Z/双击复位。座舱视角隐藏飞船本体。
- **时间与重置**：[ ] 步进时间倍率，\ 暂停；R 在安全轨道重部署。
- **物理统一积分**：推力 + 全层引力井（a = GM/r²，8ms 子步）同一套积分，
  无巡航/引力双模式；天体表面接触即撞毁→安全圆轨道重部署（HUD 高亮
  4 秒）；HUD 常显主导井束缚/逃逸能量态。
- **轨道飞行 ballistic（引力模式）**：历史模式，当前主循环不再切入——
  引力已并入统一积分（见上）。`world.gravityWells` 仍是各层引力数据源。
  多引力井由统一积分实时消费（8ms 物理子步，与时间倍速解耦）。
  **分层引力（LOD）**：每层只有「该尺度的天体」有引力效应，
  层级+距离天然过滤，井随天体实体（ref）动态移动：
  - solar 层：太阳主井（教学 GM 0.47，木星轨道圆速度 ≈0.3 AU/s 实时
    35 秒一圈）+ 八大行星井（GM=3R²，影响半径 ≈2.4R——希尔球教学放大，
    飞掠明显偏转、低速贴近切入可被行星捕获）；行星按真实根数
    开普勒椭圆运动（变速，近日点加速）。
  - stellar 层：每颗恒星一颗井，教学 GM = 0.8 ly³/s² × 真实质量
    （太阳倍数）+ 太阳井——掠过恒星轨道偏折，低速贴近可被捕获。
  - galaxy 层：银心单井（演示 GM）。cosmos 层无井，退化为惯性直线。
  - local 层：银河系/仙女座井（演示 GM 3e-5 Mpc³/s²，0.3 Mpc 圆速度
    ≈0.01 u/s）+ 三角座井——可绕仙女座弹弓/被俘获。
  - super 层：星系团井（统一演示 GM 10 Mpc³/s²）。
  - cosmos 层：无井（纯导航层），惯性直线。
- **宇宙现象**：哈雷彗星（q=0.586 AU、e=0.967、倾角 162.3° 逆行、
  近日点速度 54.6 km/s 等真实根数，数值积分椭圆轨道；恩克倾角 11.8°）
  携带背阳锥形离子尾（长度随日距反比），时间倍速下可观看
  "近日加速-弯转-远离"；彗星轨道不与行星共面是真实性质（行星本身
  倾角 ≤7°，近似共面）。
- **碰撞与继续航行**：主导井（最近）比能量 E = v²/2 − GM/r < 0 为束缚
  轨道（HUD 常显标注束缚/逃逸）；接触天体表面即撞毁→在该天体外侧
  安全圆轨道重部署（HUD 高亮 4 秒）；**R** 随时手动触发同效果的重部署。
- 飞船渲染为旅行者式深空探测器（程序化组装：六边形金箔主结构/朝前
  高增益抛物面天线+馈源桅杆/碟体托盘/尾部 RTG 桁架+散热翼/细杆天线），
  座舱视角自动隐藏；主引擎尾焰随推力点火、加力时拉长增亮并触发 FOV
  kick（仅追踪视角）；轨迹缎带实时描绘航迹（Chaikin 切角平滑 + 采样间距下限 +
  覆盖层绘制，稳定不抖、不被行星遮挡切割）；超光速以 ≈c 显示。
- **拾取（游戏式）**：屏幕准星每帧做相机射线悬停检测（命中高亮），
  点击选中信息卡——指针锁定时取准星目标，未锁定取光标射线目标。

## 4. 渲染约定

- **背景星空是球壳**：`starCloud` 把星点分布在 0.9–1.0 × spread 的球壳上
  并跟随相机平移——星点永远是"远方天球"，不会散布到世界内容附近形成颗粒噪声。
- **点大小策略**：星系/宇宙网点云用 `sizeAttenuation: false`（固定屏幕尺寸），
  保证远景形态可读；太阳系内的实体颗粒（小行星带）用衰减尺寸。
- **恒星观感 = 小亮核 + 柔光晕**（`makeGlowSprite`，AdditiveBlending），
  不用大实心球。
- **标签淡出**：主循环每帧调 `updateLabelFades(group, camPos, world.labelFadeDist)`，
  超出衰减距离的标签线性降到 0.35 透明度（教育场景保留可辨认性）。
- **Bloom**：UnrealBloomPass 全局开启；发光体（太阳/HII 区）靠 glow sprite
  控制溢出，emissive 强度保持克制避免过曝糊屏。

## 5. 数据与示意边界

- 太阳系轨道半长轴/周期、近邻恒星坐标/色温、本星系群成员方位、星系团距离：
  全部来自 `src/content/data/*` 核实数据（来源标注见 CONTENT.md）。
- 视觉放大（行星尺寸、星系盘半径在 Mpc 尺度的可见性、宇宙网拓扑）为教学示意，
  实体 `schematic: true` 并在信息卡中说明，不与真实数据混淆。
