# 宇宙航行 · 架构说明

游戏式太空飞行：驾驶飞船穿越从太阳系到可观测宇宙的六层尺度世界，
三视角（追踪/座舱/环绕）、准星拾取天体查看真实数据信息卡。本项目由
"教育向宇宙漫游"改造而来（探测球→飞船、鼠标反转修正为 FPS 惯例、滚轮变焦），
六层世界内容与引力玩法保留。

## 1. 六层尺度世界

每层是一个独立构建的 three.js 场景组，世界单位自洽、渲染策略各自最优。
跨层移动 = Navigator 切换世界（转场镜头重置到该层观测位）。

| id | 层 | 世界单位 | 内容 | 渲染要点 |
|---|---|---|---|---|
| solar | 太阳系 | AU | 太阳+八大行星（真实半长轴/周期）+主要卫星+小行星带+柯伊伯带 | 实体球（程序化贴图+自转）+点光源+轨道线；轨道飞行用真实太阳 GM |
| galaxy | 银河系 | kpc | 程序化棒旋星系（140k 星点）+银心 Sgr A*+太阳位置 | 参数化点云+HII 区+盘自转（演示速率）；轨道飞行用演示 GM |
| stellar | 星际近邻 | ly | ≤25 ly 验证近邻恒星（RA/Dec/距离→3D） | 色温点+光晕 sprite+标签 |
| galaxy | 银河系 | kpc | 程序化棒旋星系（140k 星点）+银心 Sgr A*+太阳位置 | 参数化点云+HII 区+银心辉光 |
| local | 本星系群 | Mpc | 银河、M31（可下潜）、M33、矮星系（真实方位） | 螺旋小盘+标签 |
| super | 室女·宇宙网 | Mpc | 室女团/后发团等真实星系团方位+宇宙网丝（示意） | 节点+丝点云+团辉光 |
| cosmos | 可观测宇宙 | Gpc | 宇宙网全景（示意）+CMB 边界壳+红移色 | 网点云+稀疏壳点云 |

尺度不真实处一律 `schematic: true`，信息卡标注"示意"（见 CONTENT.md）。

    camera.js        # ChaseCam 三视角：chase 追踪（横滚半跟随+加力 FOV kick）/
                     # cockpit 座舱（第一人称）/ orbit 环绕观察（只看不转）；
                     # V 循环切换，滚轮缩放跟拍距离
    ship.js          # 程序化低多边形飞船（机头 -Z）+ 引擎尾焰/辉光

  content/

## 3. 飞行模式（G 键切换）与引力遭遇

- **巡航 cruise**：W/S 前后 + A/D 左右 + Space/C 上下六向推进 + 阻尼
  （飞行辅助），Q/E 横滚，X 刹车悬停，Shift 加力（FOV 拉宽）。
  速度为教学演示倍率（HUD 标注）。
- **视角（V 键循环）**：追踪（第三人称，横滚半跟随）→ 座舱（第一人称，
  准星即航向）→ 环绕（自由观察，只看不转）。滚轮缩放跟拍距离。
  鼠标转向为 FPS 惯例（非反转：上抬头、右转右）。
- **自动驾驶（H 键）**：选中目标时**寻的飞往**（巡航物理，有限角速度
  ≤1 rad/s，速度按剩余距离收敛，进入抵达半径——拾取半径×4 + 半个
  跟拍距离封顶 3——自动断开并提示）；未选中目标则进入**自由航行
  （旅行者号）**：切入引力模式（静止自动获得圆轨道速度、时间回实时），
  仅受引力滑行，天体飞掠使轨道偏折。航行护栏（ballistic 下的
  `probe.autoVoyage`）：防坠——近天体（<minR×1.8）速度渐转向切向，
  弹弓近掠绝不着陆；防困死——深入捕获半径束缚超 8s 自动顺行加速，
  达逃逸能量即止（绕行星欣赏片刻后继续远航）。航行姿态为**顺速度方向
  （prograde，飞去哪指哪）**；深空段（引力 < 50% 推力）把速度方向缓慢
  偏向随机兴趣点（TCM，≤0.12 rad/s 保速率偏转 + 微量顺推点火示意，
  静止可起步），到点/超 24s 换下一目标，永续航行。跨层/下潜保持自由
  航行继续探索；手动推进键本帧临时接管（自动保持接合），X/G/R/H 退出。
  **载入宇宙即自动开始自由航行**（默认全自动，无需任何操控）。
  接合即切环绕视角旁观（镜头按目标尺寸只收不放；航行时约 2.5 分钟
  缓转一圈）。
- **轨道飞行 ballistic（引力模式）**：无推力阻尼，仅受 `world.gravityWells`
  多引力井作用，实时子步进积分（8ms 物理步，与时间倍速解耦——切入时
  自动回到实时，避免行星狂奔无法遭遇）。切入保留玩家已有速度；
  几乎静止时注入当前点的圆轨道速度。WASD 为小推力变轨。
  - solar 层：太阳主井（教学 GM 0.47，木星轨道圆速度 ≈0.3 AU/s 实时
    35 秒一圈）+ 八大行星井（GM=3R²，影响半径 ≈2.4R——希尔球教学放大，
    飞掠明显偏转、低速贴近切入可被行星捕获）。
  - galaxy 层：银心单井（演示 GM）。无井的层退化为惯性直线。
- **宇宙现象**：哈雷彗星（q=0.586 AU、e=0.967、近日点速度 54.6 km/s
  等真实根数，数值积分椭圆轨道）携带背阳锥形离子尾（长度随日距反比），
  时间倍速下可观看"近日加速-弯转-远离"。
- **捕获与继续航行**：主导井（最近）比能量 E = v²/2 − GM/r < 0 为束缚
  轨道（HUD 标注束缚/逃逸）；束缚且深入捕获半径、或着陆井表面 → 判定
  "完全捕获"，HUD 提示按 **R** 在系统边缘重生（沿层出生方向、清除速度）
  继续航行；切回巡航（G）亦可直接脱离引力影响。
- 飞船渲染为旅行者式深空探测器（程序化组装：六边形金箔主结构/朝前
  高增益抛物面天线+馈源桅杆/碟体托盘/尾部 RTG 桁架+散热翼/细杆天线），
  座舱视角自动隐藏；主引擎尾焰随推力点火、加力时拉长增亮并触发 FOV
  kick；轨迹缎带实时描绘航迹（Chaikin 切角平滑 + 采样间距下限 +
  覆盖层绘制，稳定不抖、不被行星遮挡切割）；演示速度超光速时 HUD
  明示"演示速度"。
- **拾取（游戏式）**：屏幕准星每帧做相机射线悬停检测（命中高亮），
  点击选中信息卡——指针锁定时取准星目标，未锁定取光标射线目标。

## 4. 渲染约定

- **背景星空是球壳**：`starCloud` 把星点分布在 0.9–1.0 × spread 的球壳上
  并跟随相机平移——星点永远是"远方天球"，不会散布到世界内容附近形成颗粒噪声。
- **点大小策略**：星系/宇宙网点云用 `sizeAttenuation: false`（固定屏幕尺寸），
  保证远景形态可读；太阳系内的实体颗粒（小行星带）用衰减尺寸。
- **恒星观感 = 小亮核 + 柔光晕**（`makeGlowSprite`，AdditiveBlending），
  不用大实心球。
- **标签淡出**：主循环每帧调 `updateLabelFades(group, camPos, world.labelFadeDist)`，
  超出衰减距离的标签线性降到 0.35 透明度（教育场景保留可辨认性）。
- **Bloom**：UnrealBloomPass 全局开启；发光体（太阳/HII 区）靠 glow sprite
  控制溢出，emissive 强度保持克制避免过曝糊屏。

## 5. 数据与示意边界

- 太阳系轨道半长轴/周期、近邻恒星坐标/色温、本星系群成员方位、星系团距离：
  全部来自 `src/content/data/*` 核实数据（来源标注见 CONTENT.md）。
- 视觉放大（行星尺寸、星系盘半径在 Mpc 尺度的可见性、宇宙网拓扑）为教学示意，
  实体 `schematic: true` 并在信息卡中说明，不与真实数据混淆。
