# 宇宙航行 · 架构说明

游戏式太空飞行 + 常开全自动旁观：松开按键飞船自己飞（点选天体即自动
导向泊车），鼠标只管环视；G 键上帝视角相机脱离飞船自由浏览，飞船继续
自动飞。从太阳系到可观测宇宙的六层尺度世界（自动 LOD 连续穿越），
准星拾取天体查看真实数据信息卡。

**真实物理口径（六层全部落地）**：天体半径/质量/引力（GM=GM 真实值，
换算真源 `content/physics.ts`）/轨道速度全部真实（地球轨道 29.8 km/s、
太阳轨道绕银心 220 km/s）；飞船为未来离子推进（0.6 m/s²，巡航
≤300 km/s ≈0.001c），速度永远低于光速——从行星际到宇宙网的航行
节奏由**自动时间倍率**承担（标题画面点击「开始」即解锁音频与操作；
跨层跃迁有黑场转场；撞毁触发震屏与红闪；接近目标按 ETA≈8 墙上秒连续配速，伴飞
按主导井 1/60 轨道周期配速、每层 timeScaleMax 封顶；[ ] 手动设置即
挂起自动，重选目标/换层恢复；泊位邻域按「到目标 ETA≈2.5 墙上秒」
自适应收尾配速，跨尺度通用）。物理积分走模拟时间（dtSim），子步长
随最强井开普勒时标自适应（≈1/20 局部轨道周期，预算 900 子步/帧）。

## 1. 六层尺度世界

每层是一个独立构建的 three.js 场景组，世界单位自洽、渲染策略各自最优。
跨层移动 = Navigator 切换世界（转场镜头重置到该层观测位）+ 自动 LOD
跃迁（飞近可下潜实体自动下潜、远离中心自动浮升，2 秒冷却；信息卡
「进入…」按钮与选中后按 `F` 主动下潜（HUD 有按键提示）；下潜落到
`dive.at` 精选的层内落点（内太阳系/银盘内/星系群内侧，杜绝「下潜进
银河系出生在银心黑洞即坠毁」类错位）；接近层界 60% 时 HUD 提示即将
浮升）+ 顶栏面包屑直达任意层。

## 3. 三模式控制：AUTO 全自动 / MANUAL 手动干预 / GOD 上帝视角

- **AUTO（默认，无按键即自动）**：松开所有键，全自动接管——点选目标
  天体则**自动导向泊车**。全程采用**期望速度矢量跟踪**：期望速度 =
  目标速度矢量 + 朝目标的制动能量剖面 `√(2·½acc·(d−park))`（目标速度
  分量天然提供拦截前置，不会被公转甩成恒距尾随），推进指令按
  `(vDes−v)/τ` 矢量误差输出并叠加引力前馈，τ 随单帧模拟时长自适应
  （离散收敛不抖振），高倍率下转向速率随倍率同步提速。泊距落在
  **目标自身引力占优区**（g_own ≥ 2×最强第三方井，近似希尔球）；
  进入交会圈（2.5 泊距进、3.5 泊距出的滞回）切换为**目标参考系交会
  制导**：相对期望速度 = 径向接近剖面 + 切向分量——自身井引力 ≤ 0.6×
  推力则**悬停伴飞**，否则取当地圆轨道速度**入轨伴飞**（引力前馈按
  向心需求缺口自动过渡），稳态即速度匹配伴飞，闭环无极限环。引力
  超出推力的天体（太阳）泊位外推到 g≈0.6×推力半径。向最强井的高速
  坠落由**防井拉起**包线兜底（按制动需求距离触发，全推力反井心）。
  第三方井主导区的近场接应退化为**背井驻点悬停**（同一速度矢量结构 +
  引力前馈抵消）。与第三方天体的穿越相撞属既有游戏机制（撞毁→重生→
  继续航行）；重部署半径额外保证引力可被推力对抗（g ≤ 0.5×推力），
  杜绝深井复坠。每帧对飞船状态做**数值守卫**（非有限值即回滚本帧
  快照），极端瞬态不再污染渲染管线。
  无目标则按所在引力井智能巡航——低速下坠切向补推**轨道保持**、
  明显超速**引力滑行**、正常**轨道巡航**、主动刹停则**空间停泊**；
  无井层沿航向惯性巡航（低速补推到 0.35 倍上限）。载入宇宙即自动
  开始，无需任何操控——鼠标只管看，飞船自己飞；锁定目标跨层失效
  （跃迁前回调清理 + 目标有效性守卫，杜绝追逐幽灵目标）。
- **MANUAL（手动干预）**：W/S 前后 + A/D 左右 + Space/C 上下六向推进，
  Q/E 横滚，Shift 加力（追踪视角 FOV 拉宽），X 反推刹车；手动飞行
  保持目标锁定（松手后自动导航从当前位置接手继续泊车；取消锁定用
  信息卡关闭），松开后按当前状态继续自动航行（W 前进时在非环绕视角机头平滑导向观察视线，便于
  指哪飞哪；追尾视角为相机相对转向——环视偏移即转动速率指令
  （操纵杆模式，满偏 ≈2 rad/s，偏移指数回零转速自停），避免机头追
  相机视线与相机锚定机尾的正反馈俯冲棘轮）。干预判定按操作分类
  严格执行（`input.ts` 的
  `OP_CATEGORIES`/`FLIGHT_CONTROL_KEYS`）：仅上述飞行操控键构成干预，
  视角/时间/系统操作绝不打断自动航行。进入干预的边沿把时间倍率钳到
  「1时/秒」档（高倍率下手动机动会一帧获得超光速 Δv 触发数值回滚），
  松手后自动配速立即接管恢复。
- **GOD（上帝视角，G 键切换）**：相机脱离飞船自由浏览——WASD 平移、
  Space/C 或 Q/E 升降、鼠标转向、滚轮调移速档、Shift 加速；飞船在
  背景中继续全自动飞行，飞行键在此视角只移动相机、绝不干预飞船；
  再按 G 相机无缝回到飞船追尾位。点选天体仍可锁定目标，看飞船
  自动飞过去。
- **大巡游（T 键）**：按各层预设的 `tourStops` 站点（各世界构建器声明，
  由内向外/由近及远的教学顺序）自动串联巡游——自动导向泊车到站伴飞，
  停留 12 秒后前往下一站，末站循环回首站；每站自动弹出信息卡充当
  讲解。到站判定复用自动导航泊距（进入 1.5×泊距圈持续 1.2 秒）；
  手动飞行干预、点击改选其他目标、跨层跃迁均终止巡游（HUD 提示），
  观察类操作与上帝视角不受影响；无路线的层（cosmos）按 T 提示
  「此尺度层没有巡游路线」。HUD 显示 `大巡游 i/N · 停留 xs` 进度。
- **视角（V 键循环）**：追踪 / 座舱（舱内 360° 转头环顾） / 环绕；
  鼠标移动 = 全向环视（100% 不干扰机头航向与自动航行），方向全视角
  统一遵循游戏常识（右移看右、下移看下）；追踪视角为**真追尾**——相机
  始终锚在机尾后上方并随飞船航向转动（环绕视角保持世界系方位不随航向），
  鼠标偏移即相对机尾的环视偏移。右键/中键拖拽平移视角，滚轮缩放，
  Z/双击复位；未锁定时左键拖拽环视超过 5px 后松手不再触发拾取
  （防「拖拽看风景」误锁目标）。座舱视角隐藏飞船本体；上帝视角下
  V 键不响应（休眠视角不被误切）。
- **时间与重置**：[ ] 步进时间倍率，\ 时钟暂停；R 在安全轨道重部署。
- **覆盖层（暂停菜单/结算/标题）**：Esc 或手柄 Start 开关暂停菜单
  （继续/设置/回到标题），打开即冻结时钟并在关闭时恢复此前暂停态
  （保留 \ 键暂停语义）；覆盖层可见期间所有游戏按键统一失效
  （每帧 keys.clear，Esc 边沿先被消费），手柄走 dpad/A/B 菜单导航；
  12 环任务链全通关在完成边沿延迟 1.4 秒弹出结算庆典（统计 +
  凯旋琶音），存档恢复到满环不重弹。
- **物理统一积分**：推力 + 全层引力井（a = GM/r²）同一套积分，按模拟
  时间推进（dtSim），自适应子步（步长 ≈1/20 最强井轨道周期，上限 900
  子步/帧，半隐式欧拉辛积分器——实时到千年/秒全倍率范围轨道稳定）；
  天体表面接触即撞毁→安全圆轨道重部署（HUD 高亮 4 秒）；HUD 常显主导
  井束缚/逃逸能量态。速度显示为真实 km/s 换算，永远不会超过光速
  （飞船性能口径远低于 c）；跨天体旅行的「快」来自时间倍率而非虚高的
  速度。
- **轨道飞行 ballistic（引力模式）**：历史模式，当前主循环不再切入——
  引力已并入统一积分（见上）。`world.gravityWells` 仍是各层引力数据源。
  多引力井由统一积分实时消费（自适应子步，与时间倍速解耦）。
  **分层真实引力（LOD）**：每层只有「该尺度的天体」有引力效应，
  层级+距离天然过滤，井随天体实体（ref）动态移动；六层 GM 全部
  真实口径（GM = G·M 真实值按层单位换算，真源 `content/physics.ts`）：
  - solar 层：GM☉=3.96e-14 AU³/s²（IAU）+ 八大行星井按真实质量；
    碰撞半径=真实表面。
  - stellar 层：每颗恒星 GM = GM☉×质量（换算到 ly³/s²），碰撞半径=
    主序 M-R 近似的真实半径——真实口径下恒星引力只在近距离可感
    （1 ly 外绕行速度 ~0.4 km/s），引力弹弓需贴到 AU 量级才明显。
  - galaxy 层：银心 Sgr A* 井（4.3e6 M☉，碰撞半径=史瓦西半径）+
    银河系盘井（GM 按太阳轨道旋转曲线匹配：220 km/s @ 8.2 kpc，
    太阳轨道圆速度真实）。
  - local 层：银河系/M31/M33/麦哲伦云井按总质量（含暗晕）——
    0.77 Mpc 外仙女座圆速度 ≈290 km/s，与本星系群真实逃逸速度同量级。
  - super 层：星系团井按团总质量（室女 ≈1.5e15 M☉ 等）。
  - cosmos 层：无井（纯导航层），惯性直线。
  飞船性能六层统一为同一真实口径（0.6 m/s²、≤300 km/s ≈0.001c，
  按 ly/kpc/Mpc/Gpc 换算）；星系团近旁出生注入的圆轨道速度超飞船
  上限时自动收敛为椭圆轨道。跨层航行节奏全部由自动时间倍率承担
  （阶梯从实时到千亿年/秒，每层 `timeScaleMax` 为该层配速顶）。
- **宇宙现象**：哈雷彗星（q=0.586 AU、e=0.967、倾角 162.3° 逆行、
  近日点速度 54.6 km/s 等真实根数，真实 GM☉ 数值积分、模拟时间驱动——
  1年/秒 倍率下 75 墙上秒跑完真实 75.3 年周期；恩克倾角 11.8°）
  携带背阳锥形离子尾（长度随日距反比），可观看"近日加速-弯转-远离"；
  彗星轨道不与行星共面是真实性质（行星本身倾角 ≤7°，近似共面）。
- **碰撞与继续航行**：主导井（最近）比能量 E = v²/2 − GM/r < 0 为束缚
  轨道（HUD 常显标注束缚/逃逸）；接触天体表面即撞毁→在该天体外侧
  安全圆轨道重部署（HUD 高亮 4 秒）；**R** 随时手动触发同效果的重部署。
- 飞船渲染为旅行者式深空探测器（程序化组装：六边形金箔主结构/朝前
  高增益抛物面天线+馈源桅杆/碟体托盘/尾部 RTG 桁架+散热翼/细杆天线），
  座舱视角自动隐藏；主引擎尾焰随推力点火、加力时拉长增亮并触发 FOV
  kick（仅追踪视角）；轨迹缎带实时描绘航迹（Chaikin 切角平滑 + 采样间距下限 +
  覆盖层绘制，稳定不抖、不被行星遮挡切割）；超光速以 ≈c 显示。
- **拾取（游戏式）**：屏幕准星每帧做相机射线悬停检测（命中高亮），
  点击选中信息卡——指针锁定时取准星目标，未锁定取光标射线目标。
  真实尺度下远处天体是亚像素点，拾取半径按 ~0.5° 视角下限放大
  （仅点选口径；泊车/碰撞/引力仍用真实半径）。
- **飞船 = 真实尺度物体（迭代 4 定稿）**：真实 ~8 m 包络按
  `shipRadiusUnits(kmPerUnit)` 换算为层世界单位（太阳系层 5.4e-11 AU、
  星际层 8.5e-16 ly），一切缩放/一切层尺寸恒定；拉远即按透视缩成尘埃，
  屏幕空间 `◇` 标记（`sizeAttenuation:false`、depthTest 被行星遮挡）在
  投影角径 <14 px 时渐显接管可见性。跟拍视距 = 12×船半径
  （`chaseDistFor`），滚轮范围 [1.2×船径, 1.4×层半径] 按层派生；
  相机 near 每帧随视距缩放（clamp 1e-12~1e6，座舱按 2×船径、上帝视角
  按层半径 1e-5），配合对数深度缓冲覆盖真实尺度全景。追尾相机位置刚性
  跟随（仅变焦距离平滑）——真尺度视距是船径量级，位置平滑的滞后量与
  视距无关，高倍率巡航时会滞后数百倍视距把船挤出视野。相机挂 0.7 强度
  零衰减补光灯（PointLight 子化 camera），船背光面任何角度可读。俯仰
  越过 ±90° 在 `Probe.steer` 内越顶翻转（yaw+π/pitch 镜像/roll+π，
  0.02 rad 滞回），forward 严格连续。星尘流（`dust.ts`，240 段
  LineSegments 盒绕相机）按 vel·dtSim 平流 + 周期 wrap，任意时间倍率下
  速度感正确。

## 4. 渲染约定

- **背景星空是球壳**：`starCloud` 把星点分布在 0.9–1.0 × spread 的球壳上
  并跟随相机平移——星点永远是"远方天球"，不会散布到世界内容附近形成颗粒噪声。
- **点大小策略**：星系/宇宙网点云用 `sizeAttenuation: false`（固定屏幕尺寸），
  保证远景形态可读；太阳系内的实体颗粒（小行星带）用衰减尺寸。
- **恒星观感 = 小亮核 + 柔光晕**（`makeGlowSprite`，AdditiveBlending），
  不用大实心球。
- **标签淡出**：主循环每帧调 `updateLabelFades(group, camPos, world.labelFadeDist)`，
  超出衰减距离的标签线性降到 0.35 透明度（教育场景保留可辨认性）。
- **Bloom**：UnrealBloomPass 全局开启；发光体（太阳/HII 区）靠 glow sprite
  控制溢出，emissive 强度保持克制避免过曝糊屏。
- **对数深度缓冲**：真实尺度宇宙要求 1e-7 AU（万 km 级特写）到 1e7 AU
  宏观视野连续覆盖，WebGLRenderer 开启 logarithmicDepthBuffer 支撑。

## 6. 验证与测试体系

- `pnpm run typecheck`：TypeScript 严格类型检查（tsc --noEmit）。
- `pnpm run test`：Vitest 自动化单元测试套件，全面覆盖动力学、开普勒计算、状态机、任务链、图鉴、巡游及纯逻辑模块（15 个套件，100 项用例，纯 Node 零 DOM 依赖或轻量 mock 隔离）。
- `pnpm run build`：生产环境打包构建，由 Vite 8 + Rolldown 驱动。配置 `manualChunks` 将底层三维引擎 `three` 独立拆分为 vendor chunk（~550 kB），应用核心逻辑单独打包为精简 chunk（~137 kB），消除构建告警并提升浏览器长效缓存命中率。
- `pnpm run smoke`：无头端到端冒烟验证——起 dev server → agent-browser（Chrome for Testing 独立 session）逐层 `nav.enter` → 断言实体/场景对象/探测球位置/update 不抛错 → 状态机/暂停菜单/通关结算/设置持久化/真实尺度与亚像素标记/掌舵与星尘验证 → 页面 error 检查 → 自动清理。
- 视觉验收：agent-browser 截六层画面比对（迭代记录见 git log）。
