# 宇宙大爆炸模拟 · 架构与迭代说明

## 0. 需求与设计目标

1. **真实的大爆炸开场**
   - 奇点爆发、超光速式暴胀、高速喷流、冲击波和火球都要可见。
   - 暴胀后奇点附近必须空旷；原子、宇宙网、天体都在远方逐步出现。

2. **小球是自由物理体**
   - 没有预定航线，不锁定目标。
   - 只受初始动量、引力、惯性和气体阻尼影响。
   - 轨迹必须是平滑弧线，不能出现锐角折返或瞬移式转弯。

3. **宇宙稀疏，结构不能扎堆**
   - 初始位置附近不能有恒星、星团、星系、黑洞。
   - 同一时间只允许一个系统进入形成阶段。
   - 天体只能在小球航行途中缓慢、随机地遇到，不能几秒内一起冒出来。

4. **大尺度结构必须真实分层**
   - 远处看到星系就只是远景表示。
   - 靠近后才按需生成内部恒星、行星、星系核、黑洞等可交互天体。
   - 远离后卸载，性能和内存可控。

5. **无限运行**
   - 模拟没有终点。
   - 小球被捕获且无法逃逸时，在捕获系统边缘重生并继续航行。
   - 航行过程中会定期在小球前方动态补充随机类型的休眠暗物质晕，
     让航线永远有新结构可探索。

6. **可持续迭代**
   - 架构和参数必须写入文档，方便继续扩展 N-body、行星二级系统、
     碰撞吸积、性能预算等功能。

## 1. 核心原则

- 宇宙可以无限运行，没有固定终点。
- 星空背景不是有限球壳/椭球，而是跟随相机的无限天球；
  小球无论飞多远，周围始终有宇宙星空，不会“跑出宇宙”。
- 暴胀阶段会把物质瞬间推到远方；之后才依次形成原子、宇宙网、
  恒星、星系和黑洞。奇点附近不会直接长出大质量天体。
- 小球没有预定航线。它只携带大爆炸赋予的初始动量，之后完全由
  `引力 + 惯性 + 星际气体阻尼` 驱动。
- 大型多天体系统采用 **按需实时生成 / 流式 LOD**：
  - 远处：只显示星系盘、星团光晕、黑洞吸积盘等低模外观。
  - 小球靠近后：才生成系统内部的恒星、行星、星系核等可交互天体。
  - 小球远离后：内部细节立即卸载，避免无限堆积。
- 小球落入天体核心或黑洞事件视界后，判定为“完全无法逃逸”，
  在捕获它的系统边缘生成下一代小球继续航行。

## 2. 模块划分

- `src/cosmos.js`
  - `CosmicSimulation`：宇宙演化、小球自由物理、细节系统生成与卸载。
  - `createCosmosRenderer`：大爆炸特效、远景天体、流式细节星体的渲染。
- `src/main.js`：主循环、控制面板、事件提示。
- `src/audio.js`：音频分析与示例音乐。
- `docs/SIMULATION.md`：本文档，后续迭代先更新这里。

## 3. 大尺度宇宙演化

- 约 62 个暗物质晕，分为四档：
  - `small` → 行星
  - `medium` → 恒星 / 星团
  - `large` → 星系 / 超星系团
  - `giant` → 超大质量黑洞
- 按径向分带分布，覆盖从近到远的漫长航线：
  - 小质量晕：约 `180 ~ 1980`
  - 中等质量晕：约 `380 ~ 3330`
  - 大质量晕：约 `650 ~ 4700`
  - 巨质量晕：约 `1000 ~ 6100`
  奇点附近是空的，不会凭空出现恒星/星团/星系/黑洞。
- 600 个普通物质粒子是远方暗物质晕周围的原初气体云，
  220 个粒子表现为从奇点喷出的高速可见喷流。
- **结构不是按时间表统一生成的**：
  - 只有小球靠近某个晕到 `SEED_AWAKEN_RADIUS`（220）内，该晕才会被唤醒；
  - 同时最多允许 3 个系统并行形成（`FORMATION_SPACING = 1.5s`），
    并且**总是唤醒离小球最近的种子**——小球飞行速度（上限 34）快于形成
    速度，若一次只允许一个系统形成，多数种子会在门控期间被甩在身后；
  - 小球靠近（150 单位内）时形成速度最高加速 2.5 倍，保证小球很早就
    “看见”结构成形，而不是贴近时才突然生成。
- 形成过程持续 3~7.5 秒（小质量行星最快，巨质量黑洞最慢），所以行星、
  恒星、星系、黑洞都是沿途提前、平滑地出现，而不是几秒内一起冒出来。
- 部分暗物质晕会沿小球初始喷射方向形成“宇宙纤维结构”，
  这只是初始条件分布，不是航线；相遇与否由后续物理决定。
- 同时，系统会定期（每 5.5 秒）回收远处仍休眠的旧暗物质晕，按质量函数
  偏中 / 大 / 巨 重新设置为新的天体系统，并投放到小球前方 220~420 单位
  远处（散乱角 0.28）。每次只生成一个，**靠其巨大引力范围把小球慢慢
  拉过去**，而不是贴脸生成；这模拟了"宇宙很空，天体距离很远，
  但引力范围很大"的真实宇宙观。
- 新投放的种子即使还未演化，也会以发光的暗物质晕光点显示（休眠点也清晰可见），
  并拥有真实质量；小球靠近时会被其引力偏转，靠近到唤醒半径后开始形成结构。
- 引力影响范围随形成进度扩张：
  `influenceRadius = 4.5 + growth * (12 + mass * 6) + mass * 1.4`，
  对巨质量黑洞可达数十单位以上，使小球在很远就能"看见"并被偏转。
- 为了能让“引力拉扯”被明显感知，小球自身的引力计算使用
  `PROBE_GRAVITY_MULT = 2.0`，只增强小球感受到的天体引力，
  不影响物质粒子演化。
- 小球速度有上限 `PROBE_MAX_SPEED = 34`：引力弹弓加速有界，
  保证“航行节奏 / 形成节奏 / 跟拍节奏”三者始终匹配。

### 3.1 性能预算与自适应降级

细节生成受两级可配置预算约束（`sim.config`，控制面板滑杆直通）：

- **细节系统上限** `maxDetailSystems`（默认 3，滑杆 1~6）：同时持有
  内部细节的系统数；超限时未生成的系统保持远景表示，并提示一次
  `⚙️ 已达细节预算上限`（每系统只提示一次）；
- **细节体上限** `maxDetailBodies`（默认 500，滑杆 100~800）：全部活跃
  系统的细节天体总数。

FPS 自适应降级（"⚙ 自动降级"开关，默认开；`config.qualityTier` 0/1/2）：

- EMA 帧率 < 40 FPS（每 5 秒评估）→ 升一档，事件提示当前档位；
- EMA 帧率 > 45 FPS 持续 10 秒 → 逐档恢复（40~45 为稳持带），避免来回跳；
- 档位 1：冻结 LOD 升级、停止创建新细节系统（存量保留）；
- 档位 2：把最远的细节系统卸载到上限一半、细节点尺寸 ×0.8；
- 关闭开关立即恢复档位 0（全质量）；HUD"宇宙"行显示当前档位（降级N）。

### 3.2 初始条件参数化

三个初始条件暴露为滑杆（`sim.config`，"🎲 重开宇宙"后生效，
localStorage 持久化、刷新后保留）：

- **纤维凝聚** `filamentStrength`（0~2，默认 1）：整体缩放暗物质晕
  贴附小球航向的概率——0 = 完全均匀各向同性宇宙，2 = 强纤维结构；
- **速度弥散** `velocityDispersion`（0.3~2，默认 1）：物质初速随机
  散布倍率（保持平均速度不变）——0.3 = 整齐的膨胀流，2 = 剧烈湍流；
- **质量偏置** `massBias`（-1~+1，默认 0）：在质量函数两端搬运数量
  份额——负值偏小质量（行星/恒星更多），正值偏大质量（星系/黑洞更多），
  中档数量不变，每档最少保留 2 个。

`CosmicSimulation` 构造函数接受 `initialConfig` 注入初始条件；
运行时滑杆只改 `config`，点"🎲 重开宇宙"（reload）后生效。

## 4. 小球的自由物理

- 初始状态：暴胀结束后从奇点附近出发，只携带惯性速度
  `PROBE_INITIAL_SPEED ≈ 24`，方向随机。
- 每个模拟步：
  1. 计算所有暗物质晕的引力，记录对小球施加强引力、需要镜头聚焦的系统。
  2. 计算当前已生成细节天体（恒星/行星/黑洞等）的引力。
  3. 进入系统内部后施加与距离相关的气体阻尼。
  4. 子步长积分 `dt <= 0.008`，保证近距离强引力下稳定。
  5. 检测是否撞入天体核心 / 事件视界；速度超过 `PROBE_MAX_SPEED` 时截断。
- 重生：速度 `PROBE_RESPAWN_SPEED ≈ 30`，在系统边缘（`系统半径 × 1.1`）之外
  重生，并给予 6 秒捕获宽限期——足够逃出大系统引力场继续航行；
  重生瞬间相机方向立即对准新航向，不会甩偏。
- 渲染层还会对小球显示位置做一阶平滑插值，消除固定物理步长造成的微抖动。
- 渲染循环由 `requestAnimationFrame` 驱动，与显示器刷新同步；物理步长
  （50Hz）与显示帧率（60Hz）不同步时，渲染层在相邻两个物理步之间按剩余
  相位插值出显示位置，保证小球运动平滑连续（个别不派发 rAF 帧的 headless
  环境会看门狗式退回 setInterval 驱动）。
- 没有任何 `target`、`visit` 或顺序表。小球可能掠过、被偏转、
  暂时绕行、被捕获，也可能直接飞走。

## 5. 按需生成的大规模多星体系统

触发条件：`小球到某个大系统的距离 < detailRadius * 1.4`（提前生成）。
卸载条件：`小球到该系统的距离 > detailRadius * 2.4`。
近距离动态加载，远距离立即卸载——性能和内存可控。

### 5.1 二级系统：靠近恒星时显现它的行星（§9.2/9.8）

集合系统（星团 / 星系 / 超星系团 / 黑洞系统）内部的恒星只有光点；
当小球贴近其中某颗恒星（距离 < `max(2.0, 恒星半径 × 55)`）时，
为该恒星即时生成 2~4 颗行星/气态巨星（`_generateStarChildren`）：

- 子天体绕**恒星本身**运动（母星是移动目标，每步用其新位置积分）；
- 对小球产生真实引力，撞上即被捕获（行星/卫星 = 大气烧蚀）；
- 渲染上追加到系统点云的预留槽位（容量 +64），显示位置 =
  母星插值位置 + 自身轨道角插值，与系统整体同步平滑；
- 子系统一旦生成就保留到系统卸载（再次靠近无需重建，有连续感）；
- 降级档位 ≥1 时不再生成新的二级系统；首次生成提示一次
  `🪐 小球贴近一颗恒星，它的行星系统在眼前显现`。

### 5.2 多级 LOD：逐步真实化

系统内部所有可能出现的细节一次性创建，并按 LOD 等级标记：

- **LOD=0 (mid)**: 进入 `R*0.7` 出现；构成第一眼印象
  - 星系：3 条旋臂上的 30~42 个亮点 + 中心黑洞
  - 超星系团：6 个星系核
  - 黑洞系统：16 颗内圈亮星
  - 行星系统：1~3 颗内行星
- **LOD=1 (near)**: 进入 `R*0.4` 出现；结构开始展开
  - 星系：80~110 颗恒星填充旋臂
  - 超星系团：每个星系核 20 颗恒星
  - 黑洞系统：30~44 颗恒星
  - 行星系统：2~4 颗行星/卫星
  - 行星：0~3 颗卫星
- **LOD=2 (inner)**: 进入 `R*0.18` 出现；最内圈细节
  - 星系：40~65 颗行星/尘埃
  - 超星系团：每个星系核 12~20 颗尘埃/行星
  - 黑洞系统：18~28 颗行星/尘埃
  - 行星：暂无

LOD 升级是"瞬时阶梯 + 平滑过渡"：
进入下一档距离阈值时立即激活该 LOD（避免错过），但渲染上用
`detail.lodLerp` 在 `dt * 1.6` 速率上从 0 平滑到目标等级——
视觉上像是"结构在凝聚"。

### 5.3 各类系统的细节生成规则

- 星云 / 尘埃云：90~150 个气体尘埃粒子 + 少量亮星。
- 恒星：3~7 颗绕行行星（含少量原行星盘气体），可见二级系统。
- 行星：0~3 颗小卫星，点缀在行星周围。
- 星团：30~45 颗（mid）+ 45~70 颗（near）= 75~115 颗真实恒星，三维球状分布。
- 星系：中心黑洞 + 30~42（mid）+ 80~110（near）+ 40~65（inner）颗恒星/行星。
- 超星系团：6 个运动中的星系核 + 每个节点 20 颗恒星 + 12~20 颗尘埃。
- 黑洞系统：16~24（mid）+ 30~44（near）+ 18~28（inner）颗恒星/行星。

这些细节天体：

- 使用较大的点尺寸 + 尺寸随距离衰减的 shader，即使在一定距离外也清晰可见
  （不再是亚像素光点，肉眼即可分辨出一片恒星/行星）；
- 持续绕中心运动；渲染时对轨道角做帧间插值，绕行天体同样平滑无抖动；
- 对小球产生真实引力；
- 与小球发生碰撞捕获；
- 在 `activeDetails` 中注册，供渲染器同步生成点云；
- 小球远离后从 `activeDetails` 移除并释放对应渲染资源。

## 6. 重生与虫洞跃迁

### 6.1 普通重生

触发条件：

- 小球撞上"单天体"（星云 / 行星 / 恒星）核心；
- 或小球撞上细节天体（恒星/行星/黑洞等集合中的成员）。

行为：

- `generation += 1`；
- 在捕获系统的边缘重新生成小球，速度沿径向 + 随机切向；
- 旧轨迹清空，播放重生冲击波；
- 事件提示第几代小球继续航行。

**差异化死亡方式**：`_respawnFrom` 接收 `deathType`，事件文案与
死亡点特效按死法区分（渲染层 `DEATH_FX` 配色/扩散/寿命）：

- `atmosphere` 坠入行星/星尘大气：🔥 烧蚀解体，暖橙单环慢扩散；
- `vaporize` 被恒星吞没：☀️ 汽化，白炽强闪快扩散、短寿命；
- `tidal` 靠近黑洞/星系核：🕳️ 潮汐撕碎，蓝白三重延迟涟漪（撕碎回声）；
- `wormhole` 虫洞逃逸不播死亡特效（全屏虫洞叠加层已足够）。

死亡点与重生点分离：特效播放在 `deathPos`（被捕获处），
重生冲击波仍在重生边缘，小球光晕颜色在重生高亮期间也跟随死法。

### 6.2 星系 / 星团 / 黑洞 不会被整体捕获

**关键设计**：星团 / 星系 / 超星系团 / 黑洞 本身是"集合"，不作为整体捕获小球。
小球只会被这些集合内部的某个成员（具体某颗恒星/行星/黑洞）捕获，
因此可以自由穿越星系、掠过星团核心、从黑洞旁擦过——前提是没有撞上具体成员。
这避免了"小球进入星系就被弹出来"的粗糙感。

`_captureRadius(s)` 只对 `star` / `planet` / `dust` 返回非零值；
`cluster` / `galaxy` / `supercluster` / `blackhole` 返回 0（集合不整体捕获）。

### 6.3 虫洞跃迁逃逸

如果小球**短时间内反复被同一系统的成员捕获重生**（普通重生治标不治本），
普通重生机制会失效。检测到这种持续捕获时（同一 `seed.idx` 在
`WORMHOLE_RECAPTURE_WINDOW = 8` 秒内反复触发），不再重生到系统边缘，
而是触发**虫洞跃迁**：

- 在小球当前位置播放全屏虫洞特效（旋转能量环 → 白闪 → 蓝色过曝）；
- 把小球瞬移到反方向 480 单位外的远方位置；
- 给予新航向 + `PROBE_RESPAWN_SPEED` 初速度；
- 重置捕获记忆（`lastCaptureSeed = -1`）；
- `generation` 不变（虫洞是逃逸不是死亡）；
- 事件提示 `🌀 小球被【...】持续捕获，触发虫洞跃迁逃逸`。

虫洞特效是一个全屏 shader 叠加层，持续 `config.wormholeDuration` 秒。

### 6.4 虫洞可配置性

三个参数已实例化为 `sim.config` 并暴露为控制面板滑杆，实时生效：

- **虫洞距离** `wormholeDist`（默认 480，滑杆 120~1000）：跃迁落点距离；
- **虫洞动画** `wormholeDuration`（默认 1.4s，滑杆 0.6~3s）：全屏动画时长，
  渲染层按 `pr.wormholeDuration` 计算进度，滑杆改变只影响之后触发的跃迁；
- **持续捕获窗口** `wormholeWindow`（默认 8s，滑杆 2~20s）：窗口内被同一
  系统再次捕获即触发虫洞；调小更难触发（更多次普通重生），调大更易逃逸。

## 7. 远景 / 近景渲染

- 星空背景：使用跟随相机的单位天球 Shader 背景 + 环绕相机星点，
  不是有限的宇宙边界。
- 远景：每个暗物质晕使用 sprite 光晕、环盘、喷流等低成本对象。
- 近景：`updateDetailVisuals()` 为每个已生成细节的系统创建独立
  `THREE.Points` 点云，写入恒星/行星的位置、颜色与大小。
- 细节系统卸载时，同步 dispose geometry/material。

## 8. 交互与视角操作

智能镜头有**三种模式**，按优先级自动切换：

1. **cruise（跟拍模式）**：默认状态。小球自由航行时，镜头从小球身后偏上
   跟随（距离 16，FOV 62°，抬高 3 单位），让小球与远方天体同时入画。
2. **interact（交互锁定 / 上帝视角）**：当某系统对小球有显著引力
   （`influenceStrength > 0.08`）且距离小于该系统半径 2.2 倍时启用。
   镜头切换为"上帝视角"——目标瞄向小球与系统中心的中点，相机从反方向
   拉远到能同时框下两者的距离，俯视角度让星系盘/黑洞吸积盘一目了然。
3. **detail（细节框选）**：当小球非常接近某个 detail body
   （距离 < 该 body 所在系统半径 0.6 倍）时启用。
   镜头进一步框选"小球 + 具体那颗恒星/行星/黑洞"，便于看清碰撞前的瞬间。

### 8.1 自动 AABB 框选

进入 interact/detail 模式时，根据以下公式计算镜头距离：
```
distForFrame = aabbRadius * 1.65 / sin(FOV/2)
targetDist   = max(16, distForFrame)
aabbRadius   = max(3, probe-to-anchor 距离 * 0.55 + 系统半径 * 0.9)
```
保证无论小球从哪个方向进入系统，镜头都能自动拉远到"一眼看清所有
交互对象"。下限 12 单位避免贴脸。

### 8.2 模式切换节奏

- 模式切换阈值：`modeLerp ∈ [0, 1]`，cruise → 0，interact/detail → 1；
- `dt * 4` 速率上升（0.25 秒拉远到位），`dt * 1` 速率下降（1 秒退回 cruise）；
- `modeHold = 6s`：进入交互模式后至少保持 6 秒，避免短闪烁；
- 倒计时结束后模式回到 cruise，ml 缓降到 0。

### 8.3 其他

- 暴胀前 2.3 秒：固定观赏奇点/火球/冲击波；
- 关闭智能镜头进入自由视角：左键拖拽旋转、右键/中键平移、滚轮缩放
  （`zoomToCursor`）、触屏单指旋转 + 双指缩放/平移；
- 三种交互均显式启用；画布设置了 `touch-action:none` 并拦截滚轮默认行为；
- 平移使用屏幕空间方向；自由视角下相机始终被无限星空包围。

### 8.4 航行信息面板

右上角（提示文字下方）常驻一块低频刷新（4Hz）的信息面板，用于观测
小球与宇宙的实时状态：

- **小球**：当前代数与速度（速度上限 `PROBE_MAX_SPEED = 34`）；
- **镜头**：智能镜头当前模式（跟拍 / 交互框选 / 细节框选），
  关闭智能镜头时显示"自由观察"；
- **最近系统**：`probe.nearestSystem` 指向的暗物质晕的类型
  （`LEVEL_LABELS`）、距离（世界单位）与阶段（休眠 / 形成中 N% / 已成形）；
- **宇宙**：已成形（生成了细节的）系统数与当前活跃细节天体总数。

面板在窄屏（≤640px）下隐藏，与图例一致。

### 8.5 事件日志与导出（可回放时间线）

- **事件日志面板**：控制面板"📜 事件日志"按钮开关，左侧时间线展示
  `sim.events` 最近 80 条（带模拟时间戳，里程碑类事件高亮），打开时 4Hz
  自动刷新、自动滚动到底部；窄屏隐藏。
- **自动日志**：模拟每 30 秒向 `sim.ticks` 写入一条状态快照
  （时间/纪元/代数/速度/位置/已成形系统数/细节体总数），
  与 toast 事件流分离，不干扰提示队列。
- **导出**：面板"⬇ 导出"按钮下载完整 JSON
  （`config` / 全部 `events` / 全部 `ticks` / 小球终态），即一次运行的
  可回放时间线；`window.__exportLog()` 供脚本调用同一份数据。
